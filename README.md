# Vinicio Mendes Roberto

AI Researcher | BSc student in Industrial Engineering at the University of São Paulo (Poli-USP)

I work on applied machine learning and software development. My projects include industrial fault diagnosis, TinyML on microcontrollers, and data pipelines with LLM-generated explanations.

## Research

I'm an ML Research Intern at Fábrica do Futuro, working on a research project in collaboration with Tractian. My work focuses on servomotor fault detection and diagnosis, including physics-based MATLAB/Simulink simulations to address scarce fault data.

In my undergraduate research, I built a three-node IoT prototype for keyword spotting on an ESP32-S3, with an int8 MobileNetV2 model trained in Edge Impulse and inference running entirely on the device.

## Selected projects

### [Credit Intelligence Pipeline](https://github.com/viniciomendesr/credit-intelligence-pipeline-lab)

A pedagogical Data/AI Engineering project using the Kaggle Give Me Some Credit dataset. The reference implementation combines a Python data pipeline, a calibrated XGBoost model, and LLM explanations of credit decisions served through a FastAPI API. It includes automated tests and programmatic checks on explanations.

**Tools:** Python, pandas, DuckDB, XGBoost, FastAPI, Claude API, pytest, Google Cloud Run.

### [EdgeTracker](https://github.com/viniciomendesr/edgetracker)

An open-source project I contribute to for verifiable physical-world data. It connects microcontrollers to signed data ingestion, real-time dashboards, and public verification of dataset integrity, with event formats for edge ML outputs.

**Tools:** TypeScript, React, Supabase, PostgreSQL, ESP32/ESP8266, Solana devnet.

### [Palpitei](https://github.com/viniciomendesr/palpitei-v1)

A football prediction game built for the Superteam World Cup Hackathon. It turns TxLINE sports data into match questions, replays, and private leagues. Its game logic and explanations use deterministic rules rather than LLM-generated match facts.

**Tools:** TypeScript, Next.js, PostgreSQL, TxLINE API.
